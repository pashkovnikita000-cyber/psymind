# PsyMind — Telegram Web App для психологических тестов

## Что строим

Telegram Mini App (Web App) для прохождения психологических тестов прямо внутри Telegram. Пользователь открывает бота, проходит тесты, получает результаты с AI-анализом который сравнивает результаты разных тестов между собой и строит общий психологический портрет.

## Стек

- **Frontend:** React + TypeScript + Vite
- **Стили:** Tailwind CSS
- **Backend/DB:** Supabase (PostgreSQL + Auth + Edge Functions)
- **Деплой:** Vercel
- **Telegram Bot:** Grammy (Node.js)
- **AI:** Anthropic Claude API (claude-sonnet-4-6) — только для сравнительного анализа между тестами
- **Telegram WebApp SDK:** @telegram-apps/sdk

## Функциональность

### Авторизация
- Вход только через Telegram (initData верификация на бэкенде)
- Никаких email/паролей
- При первом открытии автоматически создаётся профиль пользователя

### Тесты (10 штук, данные хранятся в Supabase, не скрапинг)

1. **MBTI** — 60 вопросов, 16 типов личности (INTJ, ENFP и т.д.)
2. **Big Five (OCEAN)** — 44 вопроса, 5 шкал (Openness, Conscientiousness, Extraversion, Agreeableness, Neuroticism)
3. **Тест Айзенка (EPI)** — 57 вопросов, экстраверсия/нейротизм/ложь
4. **Цветовой тест Люшера** — 8 цветов, 2 раунда выбора, интерпретация порядка
5. **Тест Шпильбергера-Ханина** — 40 вопросов, ситуативная и личностная тревожность
6. **Тест депрессии Бека (BDI)** — 21 вопрос, шкала депрессии
7. **Тест Роттера** — 29 вопросов, внутренний/внешний локус контроля
8. **Тест Тейлора** — 50 вопросов, уровень тревожности
9. **Диагностика темперамента Стреляу** — 62 вопроса, сила/подвижность/уравновешенность
10. **Тест Белбина** — 70 вопросов, командные роли

Все вопросы, варианты ответов и формулы расчёта результатов хранятся в таблице `tests` в Supabase в JSON-формате. Данные тестов — это стандартные публичные психодиагностические методики.

### Прохождение теста
- Вопросы отображаются по одному с анимацией перехода
- Прогресс сохраняется (можно прервать и вернуться)
- Таймер не нужен
- После последнего вопроса — мгновенный расчёт результата без перехода на другую страницу

### Результаты
- Сразу после прохождения: тип личности / шкала с описанием
- Каждый результат сохраняется в Supabase привязанным к telegram_id
- Визуализация: радарные/бар графики для многошкальных тестов (Big Five, Айзенк)
- Для MBTI — карточка типа с описанием сильных сторон

### AI-анализ (Claude)
- Запускается автоматически когда пользователь прошёл 2 или более тестов
- Сравнивает результаты тестов друг с другом: "твой INTJ по MBTI согласуется с высоким Conscientiousness по Big Five и низкой экстраверсией по Айзенку"
- Ищет противоречия между тестами
- Генерирует текстовый "психологический портрет" — 3-5 абзацев
- Анализ кэшируется, пересчитывается только при добавлении новых тестов
- Промпт отправляет структурированные данные результатов, не исходные ответы

### Дашборд (главный экран)
- Приветствие с именем из Telegram
- Карточка "Психологический портрет" — если AI-анализ готов, показывает краткую версию
- Кнопка "Пройти новый тест"
- Последние 3 пройденных теста с датой и кратким результатом
- Прогресс "Пройдено X из 10 тестов" с кольцом

### Каталог тестов
- Список всех 10 тестов
- Для каждого: название, кол-во вопросов, примерное время, категория (личность / эмоции / темперамент)
- Визуальный бейдж "Пройден" с датой если уже прошёл
- Сортировка: сначала не пройденные

### История
- Все пройденные тесты в обратном хронологическом порядке
- Клик → полные результаты того прохождения
- Возможность пройти тест повторно (результаты добавляются, не заменяются)

### Профиль
- Аватар и имя из Telegram
- Краткая статистика: тестов пройдено, дата регистрации
- Полный AI-психологический портрет
- Список сильных черт характера (выводится из результатов тестов)

## Дизайн

- Тема следует за Telegram (dark/light автоматически через CSS vars)
- Минималистичный: белый/тёмно-серый фон, акцент один цвет (фиолетовый #6C63FF)
- Нижняя навигация: 3 иконки — Главная / Тесты / Профиль
- Карточки с мягкими тенями, скруглёнными углами
- Анимации переходов между вопросами (slide)
- Графики через Recharts

## База данных (Supabase)

```sql
-- Пользователи
users: telegram_id (bigint PK), username, first_name, last_name, photo_url, language_code, created_at

-- Тесты (сидовые данные)
tests: id (uuid PK), slug (text unique), title, description, category, estimated_minutes, questions (jsonb), scoring (jsonb), result_types (jsonb), created_at

-- Сессии прохождения
test_sessions: id (uuid PK), user_telegram_id, test_id, started_at, completed_at, answers (jsonb), result (jsonb), is_completed

-- AI анализы
ai_analyses: id (uuid PK), user_telegram_id, analysis_text, portrait_traits (jsonb), created_at, session_ids (uuid[])
```

RLS: пользователь видит только свои test_sessions и ai_analyses.

## Telegram Bot

- Команда `/start` → кнопка "Открыть PsyMind" (openWebApp)
- Команда `/results` → краткая текстовая сводка последних результатов
- Bot token берётся из .env: TELEGRAM_BOT_TOKEN

## Переменные окружения (.env)

```
VITE_SUPABASE_URL=
VITE_SUPABASE_ANON_KEY=
SUPABASE_SERVICE_ROLE_KEY=
ANTHROPIC_API_KEY=
TELEGRAM_BOT_TOKEN=
VITE_APP_URL=
```

## Язык

## Что НЕ нужно в MVP

- Платные тесты / подписка
- Push-уведомления
- Sharing результатов
- Групповое сравнение с другими пользователями
- Мобильное приложение (только Web App в Telegram)
